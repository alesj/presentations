Blog 2 of 3 — Deep Dive

Architecture, Testing & Evaluation

Chaos engineering + LLM-as-judge: how we validate AI analysis quality with 11 chaos types, Toxiproxy network faults, and cross-provider evaluation scoring.

💥
11 chaos failure modes
delay, memory, cpu, leak, error, deadlock, threadpool, contention, GC, intermittent, exception
🌐
Toxiproxy network faults
DB chaos (slow queries, pool exhaustion) + Weather API outages at the TCP layer
⚖️
LLM-as-judge evaluation
Separate LLM scores analysis on 4 dimensions (25 pts each). Threshold: 70/100
🔄
Cross-provider scoring
AI=OpenAI + Judge=Grok (and vice versa) prevents self-evaluation bias
